\chapter{Calendrier}
\label{chap:calendrier}

L'écran \emph{Calendrier} (raccourci \texttt{Ctrl+3}) est une \textbf{grille mensuelle unifiée} qui réunit, sur les mêmes cases, deux choses :

\begin{itemize}
  \item les \textbf{tâches} (opérations de travail : semis, repiquage, récolte, désherbage, irrigation, traitement, travail du sol, autres), affichées en pastilles \emph{pleines} et colorées ;
  \item les \textbf{jalons de culture} (début/fin de récolte, mise en place, retrait prévu… déduits du calendrier de chaque plantation), affichés en pastilles \emph{en contour} pour les distinguer des tâches.
\end{itemize}

Une \textbf{légende} en bas de la grille rappelle cette distinction, et un compteur sur la barre du mois indique le nombre d'entrées affichées.

\section{Navigation}

\begin{itemize}
  \item Boutons \textbf{Mois précédent} / \textbf{Mois suivant} dans l'en-tête.
  \item Bouton \textbf{Aujourd'hui} pour revenir au mois courant.
  \item Les flèches \textbf{Gauche / Droite} du clavier feuillètent les mois.
  \item \textbf{Survol} d'une entrée : une infobulle donne son libellé complet et sa date.
\end{itemize}

\section{Glisser-déposer pour replanifier}

Une tâche peut être \textbf{déplacée} d'un jour à l'autre par glisser-déposer directement dans la grille : sa date prévue est mise à jour à la volée. Les jalons de culture, eux, sont en lecture seule (ils reflètent les dates de la plantation) : pour les décaler, modifiez la plantation correspondante.

\section{Filtrer l'affichage}

Au-dessus de la grille, deux groupes de filtres :

\begin{itemize}
  \item une rangée de \textbf{chips de catégories de tâches} (Semis, Repiquage, Récolte, Désherbage, Irrigation, Traitement, Travail du sol, Autre) ;
  \item un \textbf{interrupteur maître des jalons} qui montre ou masque d'un coup tous les jalons de culture.
\end{itemize}

Cliquer sur un chip bascule sa catégorie :

\begin{itemize}
  \item Chip activé : fond coloré + bordure renforcée. Les tâches de cette catégorie apparaissent.
  \item Chip désactivé : fond gris clair, opacité réduite. Les tâches de cette catégorie sont masquées.
\end{itemize}

Le bouton \textbf{Tout afficher} réactive tous les chips d'un coup. Les chips reprennent la couleur du premier type de chaque catégorie : si vous avez personnalisé la couleur de « Semis » dans \emph{Gérer les types}, le chip « Semis » du calendrier reflète la nouvelle teinte.

\section{Tâches générées automatiquement}

Lorsque vous créez une plantation, Pomone génère automatiquement les opérations correspondantes :

\begin{itemize}
  \item Pour une plantation annuelle : un \textbf{Semis} à la date de semis (si renseignée), un \textbf{Repiquage} à la date de repiquage (si renseignée), une \textbf{Récolte} à la date de début de récolte.
  \item Pour une plantation pluriannuelle : un \textbf{Repiquage} (mise en place) à la date d'établissement.
\end{itemize}

Chaque tâche s'affiche sous forme de pastille colorée selon son type ; une tâche terminée apparaît avec une opacité réduite.

\section{Créer, modifier, supprimer une tâche}

Le bouton \textbf{+ Nouvelle tâche} dans l'en-tête du calendrier ouvre un formulaire vierge où vous choisissez :

\begin{itemize}
  \item le \textbf{type} (parmi les huit types par défaut ou ceux que vous avez ajoutés) ;
  \item la \textbf{plantation} concernée (ou \emph{Aucune} pour une tâche générale d'exploitation) ;
  \item la \textbf{date prévue} (format \texttt{AAAA-MM-JJ}) ;
  \item des \textbf{notes} libres (observations, conditions, durée) ;
  \item la case \textbf{Tâche terminée} si elle est déjà faite.
\end{itemize}

Cliquer sur une pastille de tâche existante rouvre le même formulaire en mode \emph{édition}, pré-rempli avec les valeurs courantes. Vous pouvez alors :

\begin{itemize}
  \item changer la date, le type, l'état \emph{terminé / à faire}, les notes ;
  \item cliquer \textbf{Supprimer} pour effacer la tâche définitivement (le bouton n'apparaît qu'en mode édition, après confirmation).
\end{itemize}

\textbf{Astuce} : pour marquer rapidement une tâche comme faite, ouvrez-la d'un clic, cochez \emph{Tâche terminée} et validez avec \textbf{Enregistrer}. Re-saver une tâche déjà terminée ne change pas sa date de réalisation.

\section{Tâches récurrentes}

Une grande partie du travail d'entretien (désherbage, irrigation, observation) suit un rythme régulier. Pomone permet de créer une \textbf{série récurrente} en une seule opération.

Dans le formulaire \textbf{+ Nouvelle tâche}, cochez \textbf{Tâche récurrente}. Trois champs apparaissent :

\begin{itemize}
  \item \textbf{Intervalle} : le nombre (par ex. 1, 2, 10).
  \item \textbf{Unité} : \emph{jours}, \emph{semaines} ou \emph{mois}.
  \item \textbf{Fin (incluse)} : la date de la dernière occurrence souhaitée, pré-remplie avec un an après la date de début. Vous pouvez la modifier ou la \textbf{vider} pour une série \emph{sans fin}.
\end{itemize}

Quelques exemples :

\begin{itemize}
  \item Désherber chaque dimanche : intervalle 1, unité \emph{semaines}.
  \item Irriguer tous les 10 jours en été : intervalle 10, unité \emph{jours}, fin 31 août.
  \item Inspection mensuelle du verger : intervalle 1, unité \emph{mois}, sans fin.
\end{itemize}

\subsection*{Comment ça marche en interne}

Lorsque vous enregistrez la série, Pomone matérialise immédiatement toutes les occurrences entre la date de début et la date de fin (ou un an à l'avance si la fin est vide). Chaque occurrence devient une vraie tâche dans le calendrier, avec sa propre case « fait », ses propres notes éventuelles, etc.

Pour une série sans fin, Pomone \textbf{étend automatiquement} la liste à chaque ouverture du calendrier : vous gardez toujours un an d'avance sans rien faire.

\subsection*{Modifier ou supprimer une série}

En mode édition d'une occurrence appartenant à une série, un badge « série récurrente » apparaît pour vous le rappeler. Pour cette version (v1.0.0), le formulaire ne permet pas de modifier la règle de récurrence en place : si la série évolue (changement d'unité, de fin), supprimez les occurrences à venir une par une depuis le calendrier et recréez une nouvelle série. Un éditeur de série dédié pourra arriver dans une version future.

\textbf{Note importante} : les calculs respectent les fins de mois. « Tous les 1 mois à partir du 31 mars » donnera 31 mars, 30 avril (et non 1\textsuperscript{er} mai), 31 mai, 30 juin, etc.

\section{Gérer les types de tâches}

Pomone fournit huit types de tâches par défaut (Semis, Repiquage, Récolte, Désherbage, Irrigation, Traitement, Travail du sol, Autre) avec leurs couleurs, modifiables et extensibles. Le bouton \textbf{Gérer les types} dans l'en-tête du Calendrier ouvre l'écran dédié, divisé en deux zones :

\begin{itemize}
  \item \textbf{Catalogue} (à gauche) : la liste des types existants avec leur pastille de couleur, leur catégorie et l'indication « Utilisé » lorsqu'au moins une tâche y est rattachée. Chaque ligne porte les boutons \textbf{Modifier} et \textbf{Supprimer}. Le bouton Supprimer est désactivé pour les types « Utilisé » : il faut d'abord supprimer ou réaffecter les tâches concernées.
  \item \textbf{Formulaire} (à droite) : crée un nouveau type ou modifie le type sélectionné.
\end{itemize}

\subsection*{Créer un type}

\begin{enumerate}
  \item Saisissez un \textbf{nom} (par exemple « Désherbage thermique »).
  \item Choisissez une \textbf{catégorie} parmi les huit catégories stables. La catégorie sert à l'auto-génération : créer un nouveau « Semis » personnel ne casse pas l'auto-gen, qui prend le premier type trouvé dans la catégorie.
  \item Indiquez une \textbf{couleur} au format hexadécimal \texttt{\#RGB} ou \texttt{\#RRGGBB}. La pastille à gauche du champ affiche la couleur courante.
  \item Cliquez \textbf{Enregistrer}.
\end{enumerate}

\subsection*{Modifier un type}

Cliquez \textbf{Modifier} sur la ligne désirée : le formulaire bascule en mode édition, pré-rempli avec les valeurs actuelles. Vous pouvez changer le \textbf{nom} et la \textbf{couleur} ; la catégorie est verrouillée car elle est structurelle (changer la catégorie de « Semis » risquerait de casser l'auto-génération des tâches). Pour migrer un type vers une autre catégorie, supprimez-le et recréez-en un nouveau.

\textbf{Astuce} : renommer « Semis » en « Semis serre » préserve la catégorie \texttt{Sow} ; l'auto-générateur continue d'utiliser ce type lors de la création d'une nouvelle plantation, sans aucune modification de code.

\subsection*{Supprimer un type}

Cliquez \textbf{Supprimer} sur une ligne dont le type n'est pas « Utilisé ». Si le bouton est désactivé, ouvrez d'abord le calendrier, modifiez ou supprimez les tâches qui utilisent ce type, puis revenez sur l'écran de gestion.

\chapter{Tâches}
\label{chap:taches}

L'écran \emph{Tâches} (raccourci \texttt{Ctrl+4}) complète le calendrier par une \textbf{liste à plat} de toutes les tâches, triées par date décroissante (les plus récentes en haut), tâches terminées comprises. C'est la vue « à faire » quand on veut une liste linéaire plutôt qu'une grille mensuelle.

Chaque ligne porte :

\begin{itemize}
  \item la pastille de couleur et le libellé du type de tâche ;
  \item la plantation rattachée le cas échéant ;
  \item la date prévue ;
  \item un badge \textbf{En retard} (rouge) pour une tâche non faite dont la date est passée, ou \textbf{Aujourd'hui} (vert) pour une tâche prévue le jour même ;
  \item une opacité réduite pour les tâches déjà terminées.
\end{itemize}

Cliquer sur une ligne ouvre le formulaire de tâche (le même que depuis le calendrier) pour la modifier, la marquer faite ou la supprimer.
