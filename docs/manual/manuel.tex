% Compile with xelatex (or latexmk -xelatex). Requires:
%   - fontspec (xelatex/lualatex)
%   - TeX Gyre Heros (OTF, part of the standard `tex-gyre` package — present
%     in every TeX Live install, no system font dependency)
%   - DejaVu Sans Mono (Debian: fonts-dejavu-core, present on every Linux)

% Design: modern editorial layout — sans-serif body, generous whitespace,
