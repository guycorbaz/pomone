## What went well

- **Wiring refactor (0.1–0.4)** shrank `main.rs` ~28× without breaking a single test, via a repeatable cycle: scripted extraction with boundary assertions + **three-layer adversarial review** (Blind Hunter / Edge Case Hunter / Acceptance Auditor) confirming byte-identical relocation.
- **Parallel fan-out (0.5):** ~46 call sites across 15 files migrated by 5 concurrent subagents (disjoint files), zero compile errors — a reusable pattern for broad mechanical changes.
- **CI gates added** (source-size in 0.4, glossary-coherence in 0.6/0.8) are born-green guardrails that block future drift.
- **Terminology discipline (0.8):** avoided a wrong rename (`série`→`succession`) that would have mislabelled recurring tasks; reserved `succession` for E2.

## Challenges & recurring patterns (systemic, no blame)

1. **Reflexive `#[allow(clippy::too_many_lines)]`** added then flagged in 0.1, 0.2 *and* 0.4 — inconsistent application of the "no local allow" rule. Review caught it each time.
2. **Imprecise / over-stated completion notes** (0.1, 0.3, 0.4): "the only change is X" when Y also changed; dangling rustdoc links; stale comments.
3. **Smoke run under-done, completed *after* review** (0.2, 0.3).
4. **Process divergence:** 0.1–0.4 went through the three-layer adversarial review; 0.5–0.8 relied on compiler + tests + negative tests + CI, without it. Faster, but less adversarial scrutiny.
